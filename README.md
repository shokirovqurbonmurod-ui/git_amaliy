# Git Amaliy

Bu loyiha Git version control tizimini o'rta darajada o'zlashtirish uchun amaliy mashqlar to'plami. Frontend va backend loyihalarida Gitdan foydalanish, branching, merging va collaboration ko'nikmalarini rivojlantiradi.

## Maqsad

- Git asoslarini mustahkamlash
- Branching va merging strategiyalari
- Conflict resolution
- Remote repositoriylar bilan ishlash
- Frontend va backend loyihalarida Git integration

## Texnologiyalar

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express (kelajakda)
- **Version Control:** Git
- **Platform:** GitHub
- **Containerization:** Docker

## O'rta Darajada Ko'nikmalar

Bu amaliy mashqlar quyidagi ko'nikmalarni o'rgatadi:
- Git workflow: commit, push, pull, merge
- Branch management: create, switch, delete
- Conflict resolution techniques
- GitHub collaboration features
- Docker konteynerlar bilan Git integration

## Ishga Tushurish

1. Repositoriyani klon qiling:
   ```bash
   git clone https://github.com/shokirovqurbonmurod-ui/git_amaliy.git
   ```

2. Sahifani oching:
   - `index.html` faylini brauzerda oching

3. O'zgarishlar kiritib, commit qiling:
   ```bash
   git add .
   git commit -m "Amaliy mashq bajarildi"
   git push origin main
   ```

## Mashqlar

1. **Branch Yaratish:** Yangi branch yarating va unda o'zgarishlar qiling
2. **Merge Amali:** Branchlarni asosiy branchga merge qiling
3. **Conflict Hal Qilish:** Conflict yaratib, uni hal qiling
4. **Remote Push/Pull:** GitHub bilan sinxronlash
5. **Docker Integration:** Konteyner ichida Git operatsiyalari
